Sincronizado con Supabase

REGISTRO

Ingresa la tela con su peso y dimensiones. Al guardar se le asigna automáticamente un código de ubicación único.

COINCIDENCIAS

Ingresa el item de tela y las dimensiones que necesitas. Se muestran todas las telas registradas, ordenadas de mejor a peor ajuste.

INVENTARIO COMPLETO

Busca por código o nombre de tela para revisar o eliminar un registro.
